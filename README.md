# HW1 - Needle Autograd Framework

CMU 10-714 / 15-714 Deep Learning Systems, Homework 1.

An automatic differentiation framework built from scratch in NumPy. Implements a computational graph with forward/backward passes for common tensor operations.

## Implemented Ops

- **Arithmetic:** EWiseAdd, AddScalar, EWiseMul, MulScalar, EWiseDiv, DivScalar
- **Power:** EWisePow, PowerScalar
- **Linear algebra:** MatMul, Transpose
- **Shape ops:** Reshape, BroadcastTo, Summation
- **Activations:** ReLU
- **Math:** Log, Exp, Negate
